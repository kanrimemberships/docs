The **Action Event Occurs** trigger starts a workflow when Kanri logs a selected event. Use
this catalog to identify the event name and the label associated with each choice in the
workflow builder.

An event definition being selectable does not mean every action in the app emits it. A run
starts only when Kanri logs that event for your school and the workflow's other trigger
conditions are satisfied. If a workflow does not start, check its [run history](/workflows/run-history/)
and confirm that the relevant action actually created the event.

## Choose an event

1. Open a workflow and add or edit its trigger.
2. Choose **Action Event Occurs**.
3. Find the event that matches the change or action you want to respond to. Use the event
   name in the catalog below to distinguish similar choices.
4. Configure any other available trigger conditions, then test the workflow with a real
   matching event.

The event name is a stable identifier, such as `member.create`; the label is the readable
name, such as **Member Create**. The builder's selector is authoritative if its available
choices ever differ from this page.

## Complete selectable catalog

The catalog below is generated from Kanri's event definitions. Security and audit-only events
