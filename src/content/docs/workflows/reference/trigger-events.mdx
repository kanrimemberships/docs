The **Action Event Occurs** trigger fires when a specific event is logged in Kanri. This page lists all available event types, grouped by category.

Use this as a reference when building workflows — the event types shown here match exactly what appears in the trigger configuration in the builder.

---

## How event types work

Every time something meaningful happens in Kanri (a member is added, an invoice is paid, a schedule is synced, etc.), an event log entry is created. The "Action Event Occurs" trigger watches for a specific type of event and starts a workflow run whenever one is logged.

Each event type has a **name** (what Kanri uses internally, shown in the builder) and a **label** (the human-readable name).

Events are scoped to your school — a workflow will only fire for events in your own school, not events from other schools.
