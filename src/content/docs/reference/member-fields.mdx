## What this page will cover

A reference table for the fields stored on a member profile:

**Basic info:** first name, last name, birthday, gender, family status, photo, member number

**Contact:** email, phone number, address (street, city, state/province, postal code, country)

**Lead details:** lead status, programs of interest, source, and further details (for leads)

**Memberships (separate area):** program, status, level, promotion progress, and session balance where applicable

**Contacts (separate area):** linked people, relationship (including Emergency Contact), Can Manage, and Receive Communications settings

**Other profile areas:** notes, interactions, attendance, bookings, documents, gallery, and billing records

The completed reference will explain what each field is for, whether it is required, and any special behaviour.
