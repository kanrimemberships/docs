---
title: Schedule Fields Reference
description: Understand schedule dates and the settings for each recurring session entry.
---

A schedule is a recurring timetable template. Its entries describe the classes and times Kanri uses to create individual sessions. Review the [Schedules guide](/schedules/) before changing a schedule that already has bookings.

## Schedule details

| Field | What it means |
|---|---|
| Name | A staff-facing label, such as `Monday Evening Karate`. |
| Effective Date | The first date on which the schedule generates sessions. Leave blank to make it active immediately. |
| End Date | The first date the schedule no longer runs. Sessions stop on this date, not the day after, and the schedule is automatically deactivated. Leave blank for no end date. |
| Active status | Controls whether the schedule generates sessions. |

## Session entry fields

| Field | What it means |
|---|---|
| Class and program | The class entry. Classes are connected to one or more programs. |
| Class variant | Optional subtype of the class, if configured. |
| Day and time | The day the class repeats and its start and end times. |
| Location | The location shown for the session. |
| Member bookings | Whether members can book the session and the number of member booking spots. |
| Trial bookings | Whether trial visitors can book and the number of trial spots. Trial spots can be separate from member capacity. |

Open **Booking Overrides (optional)** for the booking settings. **Inherit from class** uses the class's setting; blank spot counts also inherit the class's counts. Set **Yes**, **No**, or a nonnegative spot count only when this recurring entry needs different rules. **Trial spots are separate** determines whether trial places have their own capacity.

## What happens when you change a schedule

Editing a schedule changes its recurring template. Use **Sync** to apply those changes to future sessions. Read the confirmation carefully: changing dates or syncing may affect future bookings. See [Sync a Schedule](/schedules/sync-schedule/) and [Activate or Deactivate a Schedule](/schedules/activate-deactivate/).
