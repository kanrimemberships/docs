Use this index to find a built-in report. Each report has its own date rules, filters, and access requirements, so read its guide before comparing results.

## Attendance

| Report | Use it to |
|---|---|
| [Attendance](/reports/attendance/attendance/) | Review records from a start date, with program, class, and confirmation filters. |
| [Historical Attendance](/reports/attendance/historical-attendance/) | Compare attendance across periods. |
| [Absentees](/reports/attendance/absentees/) | Find members who have not attended recently. |
| [Attendance Grades](/reports/attendance/grades/) | Review attendance grades and recent changes. |

## Memberships and programs

| Report | Use it to |
|---|---|
| [Memberships](/reports/memberships/memberships/) | Review membership records and their statuses. |
| [Historical Memberships](/reports/memberships/historical-memberships/) | Review membership counts over time. |
| [New Members](/reports/memberships/new-members/) | Find members whose earliest membership record was created in a date range. |
| [Only Memberships](/reports/memberships/only-memberships/) | Find members with memberships but no subscriptions. |
| [Only Subscriptions](/reports/memberships/only-subscriptions/) | Find members with subscriptions but no memberships. |
| [Promotions](/reports/memberships/promotions/) | Review promotion activity. |
| [Recent Promotions](/reports/memberships/recent-promotions/) | Find recent member promotions. |
