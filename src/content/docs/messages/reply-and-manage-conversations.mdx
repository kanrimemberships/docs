Once a [conversation](/messages/) exists, whether a member started it or you did, it behaves like
an email inbox: you can reply, search, flag important threads, and archive ones you're done with.

## Reply to a conversation

1. Go to **Messages** and open the **Inbox** tab (this is the default view).
2. Select the conversation from the list.
3. Write your reply in the box at the bottom of the thread.
4. Optionally, set a date and time to send the reply later instead of right away.
5. Click **Send** (or **Schedule**, if you set a send time).

:::note
Opening a conversation marks it read. Sending a reply does not separately change its read status.
If you marked the open conversation unread as a reminder, replying does not clear that reminder.
:::

If an SMS conversation's number is now clearly associated with a different profile, Kanri can
block the reply until that association is resolved. This is not a guarantee that every changed
or reassigned phone number is detected. Confirm the number with the family before retrying.

## Search and filter your Inbox

Use **Search messages** to find text in a message's subject or content. It is not a profile-name,
email-address, or phone-number lookup unless that detail occurs in the message itself. To find a
particular person, open their profile's Messages tab. Combine message searches with the filters:

- **Unread** — only conversations marked unread
- **Flagged** — only conversations you've flagged (see below)
- **Archived** — only conversations you've archived, hidden from the main list by default

Read/unread, flag, and archive changes apply to the shared conversation, not a private inbox for
each staff member. Coordinate unread reminders with your team.

## Mark a conversation read or unread

Open a conversation to mark it read automatically, or use the read/unread toggle on a conversation
to flip its status without opening it, useful for marking something unread as a reminder to follow
up later.

## Flag a conversation

Flag a conversation to make it easy to find again, for example something that needs a follow-up
call. Click the flag icon on the conversation, then use the **Flagged** filter to see everything
you've flagged in one place. Unflag it the same way once you're done.

## Archive a conversation

Archive a conversation once it's resolved to keep your main Inbox list focused on what's still
active. Archived conversations aren't deleted. Use the **Archived** filter to find them again, and
unarchive one if it needs attention again.
