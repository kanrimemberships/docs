The Email Builder is a drag-and-drop alternative to the [Rich Text](/messages/templates/create-a-template/)
editor, for a more polished, newsletter-style layout. It's built from stackable blocks: text,
images, buttons, and more.

:::caution
Email Builder content is HTML only. A template built this way can't be sent as SMS, and it can't
be used in a broadcast that includes any SMS recipients.
:::

## Create an Email Builder template

1. Go to **Messages** and open the **Templates** tab.
2. Click **New**, and give it a **Name**.
3. Next to **Message**, switch from **Rich Text** to **Email Builder**.
4. Enter a **Subject** (subjects always use plain rich text, even for an Email Builder template).
5. Build your layout using blocks (see below).
6. Click **Create**.

## Add and arrange blocks

Click **Add block** and choose from:

| Block | What it's for |
|---|---|
| Text | A paragraph or heading, with the same formatting as the Rich Text editor |
| Image | A single image, with alt text, alignment, and an optional height limit |
| Image + Text | An image next to a block of text, side by side |
| Columns | Two side-by-side columns of text |
| Button | A call-to-action link styled as a button |
| Divider | A thin horizontal line to separate sections |
| Spacer | Blank vertical space |
| Social Links | A row of small circular icons linking to your school's social media profiles |

Drag a block to reorder it. Click a block to open its settings, for example an image's alt text
and alignment, or a button's label and link.

:::tip
Each image block has its own upload control — just drag an image in or click to choose a file. It
uploads directly into the template and doesn't need to already be in your school's
[Gallery](/gallery/).
:::

### Limiting an image's height

By default, a tall image is capped at a reasonable height so it can't overwhelm the email —
leave **Limit height** off and it fits that default. If you want a different maximum height
(shorter or taller), turn on **Limit height** and set your own value in pixels — the
**alignment** setting above still controls whether it's centered, left, or right. With a height
limit set, you can also choose how the image fits that space:

- **Fit** (default) — shows the whole image, adding empty space above/below if needed.
- **Crop to fill** — fills the entire height, cropping any part of the image that doesn't fit. Use
  the **focal point** picker (click or drag on the image preview) to choose which part of the
  image stays visible when it's cropped.

### Social Links block

Add up to 8 links to your school's profiles — Facebook, Instagram, X, LinkedIn, YouTube, TikTok,
or a general website. Choose the platform and paste the profile URL for each one, and set the
row's alignment (left, center, or right).

## Reuse layouts with saved sections

If you build a layout you'll want again, for example a header with your logo and a button, select
**Save canvas as section**, name it, and it's saved for reuse in any future Email Builder
template. Saved sections appear under **Custom sections** in the same panel where you add blocks.
Kanri also ships with a set of built-in **Preset** sections (an intro paragraph, a call-to-action
button, a two-column layout, and others) you can insert as a starting point.

## Email-wide settings

Under **Email Settings**, you can set:

- **Font** — the font used across the whole email
- **Email preview text** — the short snippet shown next to the subject line in most email apps,
  before the email is opened. Kanri fills this in automatically from your content, but you can
  type your own to override it, and reset back to automatic any time.
