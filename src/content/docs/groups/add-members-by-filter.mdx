## Planned topics

- Open a group and choose the **Dynamic Filter** assignment option.
- Choose member fields and related information to create filter conditions.
- Combine conditions that all must match or any of which can match.
- Save the filter and preview the profiles it currently includes.
- Understand that the group membership can change as member details change.
- Edit or remove a filter assignment without changing member records.
- Combine filter assignments with individually selected members or [program assignments](/groups/add-program-to-group/).
