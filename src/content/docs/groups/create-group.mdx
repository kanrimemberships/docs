Groups collect people for organization and communications. Create the group first, then choose whether to add specific members, members from a program, or members who match a filter.

## Create the group

1. Open **Groups** and select **New Group**.
2. Enter a name staff will recognize, such as *Junior Tournament Team* or *Members with expiring documents*.
3. Select **Create**.
4. On the group page, choose **Assign** to add people or define a matching rule.
5. Preview the members before using the group for a message.

Group names must be unique within your school. Choose a name based on the group's purpose, not just the date of the next message, if you plan to reuse it.

## Choose assignment types

- **Individual Members**: pick specific profiles for a hand-selected group.
- **Program & Level**: include active members of a program, optionally limited to a level range.
- **Dynamic Filter**: define profile conditions that Kanri reevaluates when resolving group members.

You can combine assignment types. If a member matches more than one, the preview lists them once. See [Add Members to a Group](/groups/add-members-to-group/), [Add a Program](/groups/add-program-to-group/), and [Add by Filter](/groups/add-members-by-filter/).

## Example

For a one-time *Saturday Demo Team*, create the group, add the invited members individually, then preview and send the event details as a [broadcast](/groups/send-broadcast-to-group/). For a reusable group of all active members in a program, use a program assignment instead.
