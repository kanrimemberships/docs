## How group membership works

A group is a named collection of people connected to your school. You can use it to organize members and target a [broadcast](/messages/send-a-broadcast/). Group assignments determine who is included. You can combine multiple assignment types in one group.

| Assignment type | Who it includes |
|---|---|
| **Individual members** | Specific profiles you select. They stay in the group until you remove the assignment. |
| **Program and level** | Members with an active membership in a selected program. You can limit the group to a level range. Membership updates change who matches. |
| **Custom filter** | Members whose profiles match conditions you choose in the filter builder. Kanri checks the filter against member records when resolving the group. |

If a person matches more than one assignment, they are still included only once.

## Common tasks

- [Create a Group](/groups/create-group/): name a group and open its member list.
- [Add Members to a Group](/groups/add-members-to-group/): select specific profiles to include.
- [Add a Program to a Group](/groups/add-program-to-group/): include members by program and optional level range.
- [Add Members Using a Custom Filter](/groups/add-members-by-filter/): define conditions to include matching member profiles.
- [Send a Broadcast to a Group](/groups/send-broadcast-to-group/): review recipients and send a message.

:::tip
Use individual assignments for a hand-picked list, program assignments for an enrolled cohort, and a custom filter when you want the group to follow changing profile details.
:::

## Worked example: a junior tournament announcement

1. Create a group named *Junior Tournament Team*.
2. Add a program assignment for the junior program, limited to the levels attending the tournament.
3. Preview the members before sending anything.
4. Add individual members for extra invitees. To exclude someone matched by a program or filter,
   change that matching rule instead.
5. Send the tournament details as a [broadcast](/groups/send-broadcast-to-group/), then review delivery in the message outbox.

The preview helps catch an incorrect program or level range before you contact families. Group membership controls the intended audience; it does not itself send a message.

Assignments add people; they do not subtract them. Removing an individual assignment does not
exclude someone who still matches a program assignment or filter.

## Review groups before sending

Membership can change when program assignments or custom filters match changing member records. Preview the group's current members before a time-sensitive broadcast. If someone appears more than once through different assignments, Kanri includes them once in the resolved group.

For message delivery, see [Send a Broadcast](/messages/send-a-broadcast/). For member profile searches, see [Search and Filter Members](/members/search-and-filter/).

The preview lists member profiles. A broadcast can also include eligible linked contacts and omit
people without the selected contact method. Shared delivery addresses can be combined, so the
preview count is not a guaranteed message count.
