---
title: Read an Event Log Entry
description: How to navigate and filter the school-wide event log.
---


Go to **Logs → Events** to see recorded school activity. Each row shows the type of action, who
performed it (or "System" when no actor name is available), and when it happened. Click a row to see full
details in the panel on the right — for a wider screen, this opens alongside the list; on a
narrower screen, it opens its own page.

## Filtering the log

Use the filter bar above the list to narrow down the events shown. You can combine any of these at
once:

- **Event Type** — pick one or more specific kinds of events (for example, only membership changes
  or only billing events) from the dropdown.
- **Since / Until** — show only events between two dates.
- **All Sources** — **User Action** shows events not linked to a queued job; **Job Queue** shows
  events linked to a job. A staff-started bulk send can be linked to a job, so this is not the
  same distinction as a person versus an automatic action.
- **Performed by (first name) / (last name)** — show only events performed by a staff or portal
  user matching that name.
- **System only** — show events with no recorded user, instead of filtering by name.
- **Affected member** — finds events about the profile itself or events that explicitly recorded
  the member connection. It can include membership, subscription, or invoice activity, but it does
  not search every indirect relationship.
- **Object ID** — if you have the internal ID of a specific record (for example from a support
  conversation), search for it directly.
- **IP address** / **User agent** — narrow recorded network and browser information when present.
  These details can help an investigation, but do not confirm a specific device or physical location.

Filters apply together (not one-or-the-other) — for example, you can look for events "performed by
Jane" **and** "since last Monday" at the same time.

**System only** replaces the performed-by name filters and means no user was recorded.
It does not necessarily mean **Job Queue**. Dates use the school's timezone and include both
selected boundary dates. IP and browser details may be absent and are not proof of a person's
physical location.

The event log is a **Beta** feature. It may omit actions or details, so do not treat it as a complete
audit trail. See [Event Log](/logs/) for this limitation and the main search steps.
