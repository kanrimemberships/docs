---
title: Member Event Log
description: Review recorded events associated with one member's profile.
---

Open a member's **Logs** tab to see events whose main affected record is that member.
You need **View Event Log** and **Manage Members** permissions, and your school needs event-log
access. The school-wide event log is available under **Logs → Events**.

## Find a member event

1. Open the member's profile.
2. Select **Logs**.
3. Set a date range or event type if you need to narrow the list.
4. Select an entry to review its details.

The detail view may show who performed the recorded action, when it happened, and the details Kanri captured. Use the event type and timestamp to compare it with other changes to the member's record.

## Know the limits

Event logs are currently a **Beta feature**. Not all actions may be logged, and some details may be incomplete. The member log is not a full transcript of messages, billing activity, or every change. Check the relevant member, invoice, or subscription page for the current record, and contact support if a critical event is missing or unclear.

An event about a membership, subscription, invoice, or another linked record can be absent from
this tab because that other record is the event's main object. Search **Logs → Events** with
**Affected member** for a broader search. Even that filter only finds events that recorded the
member connection; it cannot reconstruct every indirect relationship.
