---

Use Gallery uploads for files shared across the school. For files that belong to one person, use the [member gallery](/members/gallery/).

## Upload files

1. Open **Gallery**, or open the destination folder first.
2. Choose **Upload Files**.
3. Drag files into the upload area or select files from your device. You can also use **Open Camera** on a supported device.
4. For each file, enter a clear **Name** and optional **Description**.
5. Choose a folder if you started from the Gallery root.
6. Set **Public** only if members should be able to view the item.
7. Select **Next** to review another file or **Finish** to complete the upload.

You can skip an individual file during the review. Check the final Gallery folder to confirm the expected items were added.

## Organize and share

Use a date or event name in the file title, such as **Summer grading - 2026**. If you want members to see the file, the item, its folder, and every parent folder must be public. See [Share Gallery with Members](/gallery/share-gallery/).

## Download or remove an item

Open the item and select **Download** to save a copy. Staff with **Manage Gallery** can use its edit or delete action. Removing a gallery entry does not remove a file that is still in use elsewhere, such as a member's profile photo.

Gallery files use your school's shared storage allowance. Review [storage allowances and costs](/reference/plans/#storage) before a large upload. A downloaded copy is outside Kanri's control even if the gallery item is later hidden or removed.
