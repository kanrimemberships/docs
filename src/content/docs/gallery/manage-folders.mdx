---
title: Manage Folders
description: Create, nest, rename, and share folders in the school Gallery.
---

Folders keep the school Gallery organized by event, term, or activity. You can create nested folders, add descriptions, and choose whether a folder is public.

## Create a folder

1. Open **Gallery**.
2. Choose **New Folder**. To create a nested folder, first open its parent folder.
3. Enter a clear **Folder Name** and optional description.
4. Choose a parent folder only if needed.
5. Set **Public** if members should be able to view the folder.
6. Select **Create Folder**.

Kanri requires unique folder names within the same parent, including at the Gallery root. You can reuse a name in a different folder or a different member's gallery. A structure such as **2026 → Summer Camp** is easy to browse.

## Edit or delete a folder

Open the folder and choose **Edit Folder** to change its name, description, parent, or visibility. You cannot move a folder inside one of its own descendants.

Before deleting, review the folder and its subfolders and download anything you need to keep. Deleting a folder removes all its items and subfolders, including deeply nested content. If a file is still used as a member's profile photo, that photo stays on the member record.

## Public and private folders

Use **Public** only when you intend the folder to be visible to members. Every parent folder must also be public. You cannot make an item or folder public beneath a private folder.

Changing a public folder to private also makes all its subfolders and their items private. Making the folder public again does not automatically publish those items or subfolders. Staff with **View Gallery** can still browse private content.

Review [Gallery sharing](/gallery/share-gallery/) before publishing identifiable photos.
