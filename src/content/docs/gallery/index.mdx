The school Gallery is a shared place for photos and files. Use folders to organize content by event, term, or activity. Each folder and item has a **Public** setting, so decide who should be able to see it before sharing.

Here, **Public** allows signed-in users with access to your school to browse the content. The item and every parent folder must be public. Staff with **View Gallery** can also see private gallery content. If your school uses an automatic gallery on its public website, eligible public school-gallery items may appear there too. See [Gallery sharing](/gallery/share-gallery/) before publishing.

## School gallery or member gallery?

- Use the school **Gallery** for content shared across your school, such as event photos.
- Use a [member gallery](/members/gallery/) for that person's progress photos, certificates, and other member-specific files.
- Use [Documents](/documents/) for files sent for signature or records managed as member documents.

## Upload and share

1. Create a [folder](/gallery/manage-folders/) for the content.
2. [Upload files](/gallery/upload-files/) and give them clear names.
3. Decide whether the folder and each item should be public.
4. Review the member-facing view before directing people to the content.

You can add multiple files in one upload flow and provide a name and optional description for each. The app's file picker determines which file formats are accepted.
