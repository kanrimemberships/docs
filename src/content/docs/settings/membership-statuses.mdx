---
title: Membership Statuses
description: Create active and inactive status labels and choose the school's defaults.
---

Membership statuses label whether a member's program enrolment is active. The status is separate from the member's billing subscription.

You need **Manage Settings** and the Memberships feature to manage these statuses.

## Create a status

1. Open **Settings → Membership Status**.
2. Select **New Membership Status**.
3. Enter a unique name, such as **Active**, **Paused**, or **Completed**.
4. Turn on **Active** if memberships with this status should count as active.
5. Select **Create Membership Status**.

Choose the active flag based on how your school uses the status. For example, a paused enrolment may need an inactive status if the member should not be treated as currently enrolled.

## Set the default statuses

1. Open **Settings**.
2. Choose a **Default Active Membership Status** for new active memberships.
3. Choose a **Default Inactive Membership Status** for memberships when they end.
4. Save the settings.

Kanri requires one active and one inactive default. You can choose from the statuses that match each state.

Take care when editing a status: changing its name or active flag affects all current and past memberships, including historical data. If you change the active flag, memberships using that status can switch between active and inactive.
