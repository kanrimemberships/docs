---
title: Behaviors
description: Configure school-wide rules that change how Kanri handles accounts, check-in, bookings, and billing.
---

Behavior settings are school-wide rules. You need **Manage Settings** to change them. They affect what Kanri does when members sign in, book classes, or pay invoices. Review the description beside each setting and test important changes before your staff rely on them.

## Behavior groups

- [General Behaviors](/settings/behaviors/general-behaviors/): account linking, age-rule enforcement, and member-manager uploads.
- [Kiosk Behaviors](/settings/behaviors/kiosk-behaviors/): subscription checks, trial sign-in, mobile check-in, promotions, and kiosk messages.
- [Subscription Behaviors](/settings/behaviors/subscription-behaviors/): multiple subscriptions, billing-plan prices, program access, and receipts.
- Billing Notifications: invoice emails and the retry schedule for failed subscription payments.
- Documents: the default deadline for auto-sent documents.
- Shop & Inventory: automatic fulfilment and overselling rules.

Some sections only appear when the related school feature is enabled. Changes save individually; confirm the success message before leaving the page.

## Before changing a behavior

1. Identify the problem the setting should solve.
2. Read the setting description and review the related guide.
3. Consider which existing members, bookings, or payments the rule affects.
4. Change one setting at a time.
5. Test the member or staff experience after saving.

If a behavior has an unexpected effect, return to **Settings → Behaviors** and review the saved value.
