Kanri builds the sending address from your **Email Sender ID** and an email domain. For example, sender ID `hello` and domain `springfieldkarate.com` produce `hello@springfieldkarate.com`.

You need owner access to change the school's sender details.

## Set the sender details

1. Open **Settings → Branding**.
2. Enter a recognizable **School Name**.
3. Optionally enter a **Display Name**. Kanri uses it on emails, sent documents, and lead or intake pages. If blank, Kanri uses the School Name.
4. Enter an **Email Sender ID** using 3 to 64 letters, numbers, or hyphens. It cannot start or end with a hyphen.
5. If you have an active email domain, select it under **Sending Domain**. Otherwise, Kanri uses your school's default subdomain address.
6. Save the settings and check the sender preview.

For example, use `hello` as the sender ID for general school updates, or `billing` for payment messages if that matches how your school handles replies.

## Connect a custom sending domain

If you already have an active email domain, return to Branding and select it as the **Sending Domain**. Adding a new email domain is not currently self-service for school staff; contact Kanri support to ask about setup.
