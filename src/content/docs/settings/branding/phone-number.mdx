---
title: SMS Phone Number
description: Search for and select a dedicated phone number for your school's Kanri messages.
---

If your school uses Kanri's messaging features, an owner can select a dedicated phone number under **Settings → Branding → Phone Number**. The page requires the Communications Hub feature.

## Search for a number

1. Open the **Phone Number** page.
2. Search using a location, region, area code, postal code, or text the number should contain.
3. If a location search returns no results, try adding a region or a different area code.
4. Review the number and its location, then select **Select**.
5. Confirm your choice.

The selected number is connected to Kanri's messaging service. The page warns that changing it later requires contacting support, so choose carefully.

The available numbers depend on the locations supported by the phone provider. If you cannot find a suitable number, try a broader search or contact support.
