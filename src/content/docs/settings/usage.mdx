title: Usage Credits
description: Review your school's usage-credit balance and configure automatic recharges.
---

The **Settings → Usage Credits** page shows included and purchased usage credits, the combined balance, and when included credits reset. It also lets you buy credits and manage automatic recharges. You need owner access and the Communications Hub feature.

## Review the balance

Check **Current Balance** before enabling a feature that uses credits. Included and purchased credits are shown separately. The page displays the next reset date for included credits when one is available.

## Buy credits

1. Confirm that your school has a payment method on file.
2. Open **Settings → Usage Credits**.
3. Enter an amount from 10 to 1,000 in your school's currency.
4. Select **Purchase** and confirm.

If Purchase is unavailable, check the payment method shown on the page or open [Account settings](/settings/account/).

## Set up automatic recharge

1. Turn on **Enable automatic credit purchases when balance is low**.
2. Set the **Minimum Balance** that should trigger a purchase. It must be from 5 to 100.
3. Set the **Purchase Amount**, which must be from 10 to 1,000.
4. Select **Save Settings**.

For example, if you set the minimum balance to 15 and the purchase amount to 30, Kanri can automatically buy 30 in credits when the balance falls below 15. Choose values your school is comfortable having charged automatically.

Turn off automatic recharge if you do not want further automatic purchases. Review the current balance and payment method regularly.
