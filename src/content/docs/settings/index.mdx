Settings control how your school uses Kanri. Changes can affect staff access, member check-in, booking rules, and messages, so review each setting before changing it.

## Find a settings area

| Area | Use it to |
|---|---|
| [General Settings](/settings/general/) | Set your school's timezone, address, and default membership statuses. |
| [Behaviors](/settings/behaviors/) | Choose school-wide rules for member accounts, kiosk, subscriptions, and billing. |
| [Roles](/settings/roles/) | Create roles and control what staff can view or manage. |
| [Kiosk Messages](/settings/kiosk-messages/) | Show required messages or notices during kiosk check-in. |
| [Booking Settings](/settings/booking-settings/) | Set booking windows and same-day rules. |
| [Branding](/settings/branding/) | Configure the school's visual identity and sender details. |
| [Membership Statuses](/settings/membership-statuses/) | Define the status labels available for memberships. |
| [API Keys](/settings/api-keys/) | Create and manage keys for authorized integrations. |
| [Connected Domains](/settings/domains/) | Connect a domain for school app access or email. |
| [Usage Credits](/settings/usage/) | Review usage credits and automatic recharges. |
| [Evaluation Forms](/settings/evaluations/) | Configure the form sent during member onboarding. |

Other settings pages cover your school's [Stripe account](/settings/account/), [SMS phone number](/settings/branding/phone-number/), and [referral-source tracking](/settings/referral-types/).

## Who can change settings?

Settings access depends on the staff member's role and permissions. Sensitive areas such as Branding, API keys, connected domains, and payment-account management require owner access; other settings may require a specific permission and school feature. If a setting is missing, ask your school administrator to check your access rather than using another person's login.

## Set up the essentials first

When opening a school, confirm the timezone and address, choose the default active and inactive membership statuses, set booking and subscription behaviors, and invite staff with only the permissions they need. See [Configure Initial Settings](/getting-started/initial-settings/).
