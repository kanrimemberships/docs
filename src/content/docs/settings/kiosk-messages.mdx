Kiosk messages give members relevant information while checking in. A message can apply to one program or to the whole school. You need **Manage Settings** and the Kiosk feature to manage them.

## Create a message

1. Open **Settings → Kiosk Messages**.
2. Select **New Message**.
3. Choose a program, or leave **Program** blank for a school-wide message.
4. Choose the message **Type**:
   - **Required** means the member must acknowledge it before signing in.
   - **Banner** displays the message as a notice on the confirmation screen.
5. Enter a short, clear message.
6. Select **Create Message**.
7. Test a check-in for the selected program.

For example, use a required message to ask members to check in with staff before entering a restricted training area. Use a banner for a reminder about an upcoming event.

## Edit or remove a message

Open the message to change its program, type, or text. If it is no longer relevant, delete it so members do not continue seeing outdated instructions.

Keep the wording suitable for a shared screen. Do not include private payment or health information in a kiosk message.
