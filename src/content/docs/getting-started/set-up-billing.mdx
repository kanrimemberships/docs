---
title: Set Up Billing
description: Create a billing plan and price, add a member payment method, and create the first subscription.
---

Set up the billing rules first, then assign a member to them:

1. Create a **billing plan** and its first **price**.
2. Add a member's payment method if Kanri will collect online payments.
3. Create a **subscription** for the member using the plan and price.

An invoice records a specific amount, such as an equipment or registration fee, and is also used for scheduled subscription payments.

## Before you begin

- You need permission to manage billing.
- Connect the school's Stripe account before using Kanri's supported online payment flows. If your school records cash or payments collected elsewhere, you can still use billing records without charging through Stripe.
- Decide the offering and price type in advance. Common choices are recurring tuition (**Ongoing**), a set number of installments (**Fixed Term**), a one-time amount for a term (**Paid in Full**), a prepaid block (**Session Block**), or usage-based charges (**Per Session**).
- If staff need several rates on one plan, confirm **Settings → Behaviors → Billing plan mode** is **Multiple**. The setting is school-wide.

## 1. Create a plan and its first price

1. Go to **Billing → Plans** and select **New Plan**.
2. Enter a clear **Plan Name**, such as *Adult Karate*.
3. Choose a **Price Type**. The form will show the fields for that type.
4. Enter the amount and schedule. For a C$120 monthly recurring plan, choose **Ongoing**, enter `120`, and set the interval to `1 Month`.
5. If applicable, choose the term length, number of payments, session block size, or per-session billing timing.
6. Review any optional settings. **Trial Plan** labels the offering but does not itself delay the first payment. If your school has the Documents feature, you can optionally select a contract template and auto-send preference.
7. Select **Create Plan** and confirm the price appears as expected.

The school's billing currency is used for the price. You do not select a separate currency on this form. For additional rates in Multiple mode, follow [Add a Price](/billing/billing-plans/add-price/).

## 2. Add a payment method when collecting online

To save a card for online collection, add a payment method to the member before creating a subscription:

1. Open the member's profile and go to **Billing → Payment Methods**.
2. Select **Add Payment Method**.
3. Enter a label and select who is responsible for payment in **Bill To**.
4. Choose **Email Link** or **Collect via Terminal**. Both setup options collect card details.
5. Ask the payer to complete the secure payment-method setup. Confirm the method appears on the member's profile before continuing.

If the member pays cash or by a method collected outside Kanri, you can skip saving a card and choose the matching payment arrangement on the subscription or invoice. Without a saved payment method, staff must use **Invoice Now** on an upcoming subscription payment to create its invoice.

## 3. Create the subscription

1. Open the member's profile and select **Subscriptions**, then **New Subscription**.
2. Select the billing plan.
3. If the plan has multiple prices, select the correct price. Check the price name, amount, and interval rather than relying only on the default.
4. Choose the required **Payment Method (legacy)** category and **Payment Method Type**. Choose **Saved payment method** and select the member's saved method for automatic collection; other types record cash, terminal, checkout, or manual handling without selecting a saved method.
5. Set the **Start Date** and, when shown, **First Payment Date** deliberately. Do not assume the plan's Trial label changes the first payment date.
6. Review the summary and select **Create Subscription**.

## Confirm and troubleshoot

Open the member's subscription and confirm the plan, price, dates, and payment method. Upcoming and invoiced schedule records appear in the subscription's payment details; check the linked invoice's charge status to confirm an actual payment attempt. An attempted payment is not proof that funds reached the school's bank account; use **Settings → Payouts** for the connected-account payout interface.

If the plan auto-sends a contract, confirm that it has been signed; scheduled invoice creation waits for the signature.

If the payment does not happen when expected, check the [subscription troubleshooting guide](/billing/troubleshooting/subscription-not-charging/). If a payment failed, see [Failed Payments](/billing/troubleshooting/failed-payments/).
