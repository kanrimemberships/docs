Use this guide to add a student and enrol them in a program. A **member profile** stores the person's details. A [membership](/members/memberships/) records which program they are enrolled in. Billing is set up separately with a [subscription](/members/subscriptions/).

:::note
The **Lead** profile type requires a Professional or Enterprise plan. [Compare plans →](/reference/plans/)
:::

## Before you start

Create at least one [program](/getting-started/create-your-first-program/) before assigning a membership.

## Step 1: Create the member profile

1. Go to **Members** in the main navigation.
2. Click **New Member**.
3. Choose **Member**.
4. Enter the member's first and last name. These are the only required fields. You can also add their gender, birthday, phone, and email.
5. Click **Create Member**.

Kanri assigns the profile a unique [member number](/members/member-number/). It guides you through adding contacts and then setting up memberships or billing. You can add the member's address from the **Address** card on their profile.

## Step 2: Add a contact

Add a parent, guardian, or emergency contact when you need someone linked to the member's profile.

1. Open the member's profile and select **Contacts**.
2. Click **New Contact**.
3. Create a new contact or link an existing member profile.
4. Choose the relationship, such as **Parent** or **Emergency Contact**.
5. Turn on **Can Manage** if the contact should manage the member's account.
6. Turn on **Receive Communications** if the contact should receive messages sent to the member.
7. Save the contact.

See [Contacts](/members/contacts/) for the available relationship and permission settings.

## Step 3: Assign a membership

1. Open **Memberships** on the member's profile.
2. Click **New Membership**.
3. Select the **Program**.
4. Select a starting **Level** if the program uses levels.
5. Choose the membership **Status**. Kanri selects your school's default active status.
6. Enter **Sessions Remaining** only if this membership has a limited number of sessions.
7. Save the membership.

The membership links the student to the program. It is separate from the student's [subscription](/members/subscriptions/), which records their billing arrangement.

## Member numbers and kiosk check-in

Every profile receives a unique member number when it is created. Members can use the number, or search by first name, to sign in at the [kiosk](/kiosk/). See [Member Number](/members/member-number/) for details.

## Next step

If the member will pay through Kanri, [set up billing](/getting-started/set-up-billing/). You can also keep a subscription on file for payments handled outside Kanri.
