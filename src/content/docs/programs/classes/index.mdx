A **class** is a type of training, such as Beginner Karate or Open Mat. A **class variant** is an optional subtype, such as Kata or Sparring. A class can be used in a schedule to create its recurring sessions.

## Create a class

1. Open **Classes** and select **New Class**.
2. Enter a name and choose the related program.
3. Optionally set age limits and booking spots for members or trial visitors.
4. Turn on **Counts towards attendance** if attendance should count toward level progression. It starts off on the new-class form.
5. Save the class, then add a [variant](/programs/classes/create-class-variant/) if you need one.
6. Add the class to a [schedule](/schedules/create-schedule/).

Booking spots can be unlimited when left blank. Trial spots can be separate from member spots, so check both limits when planning capacity.

Classes are managed from the school's **Classes** menu. A class can have several program assignments in its **Program Eligibility** section, each with its own level limits and booking switches. Setting capacity does not turn bookings on; enable them on the program assignment or override them on the schedule entry.

## Control who can sign in

When group-based kiosk access is enabled, you can optionally choose allowed groups for a class. Members in any selected group may sign in; leaving the group list empty allows all members. This setting controls kiosk access, not membership in the program.

## Attendance and progression

The **Counts towards attendance** setting belongs to the class. If it is off, attendance at sessions of that class does not count toward a level's minimum-class requirement. Review it before staff begin taking attendance.

## Example

For **Adult Karate**, create **Karate Fundamentals** and **Open Mat** as separate classes. If the Fundamentals class includes distinct training formats, create variants such as **Kata** and **Sparring**. Schedule each class at its usual time.
