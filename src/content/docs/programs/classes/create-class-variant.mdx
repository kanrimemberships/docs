---
title: Create a Class Variant
description: Add an optional subtype to a class, such as Kata or Sparring.
---

A variant is a named option within a class. Use variants when one class has distinct formats that staff need to schedule separately. If the formats do not need separate scheduling or tracking, keep one class without variants.

## Add a variant

1. Open **Classes** and select the class.
2. Find **Class Variants**. Use its list control, then select **New Variant**, or use the add control directly on the class.
3. Enter a short, clear name, such as **Kata**.
4. Select **Create Class Variant**.
5. Repeat for other variants, such as **Sparring**.
6. When you create a schedule, select the appropriate class and variant for each timetable entry.

## Example

You could use one **Advanced Karate** class with **Kata** and **Sparring** variants if both formats share the same class rules but occur at different times. Create separate classes instead if they need different attendance, booking-capacity, level, or access settings.

You need permission to manage programs to create variants. The name is required and must be different from the other variants in that class.
