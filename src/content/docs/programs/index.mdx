A **program** is an activity your school offers, such as Adult Karate or Junior Ballet. It groups related classes and levels, and members can have a membership in the program.

## How programs fit together

- **Program**: the activity, such as Adult Karate.
- **Class**: a type of session within the activity, such as Beginner Karate.
- **Class variant**: an optional form of that class, such as Kata or Sparring.
- **Schedule**: a repeating timetable for a class.
- **Level**: a position in the program's progression, such as White Belt or Yellow Belt.
- **Membership**: a member's enrolment in the program and current level.

Classes are managed from the school-wide **Classes** menu. One class can be assigned to several programs; its **Program Eligibility** section holds each program's level limits and booking options.

For example, create an **Adult Karate** program, add a **Karate Fundamentals** class, schedule it for Monday evenings, and set up the belt levels members progress through. See [Create a Program](/programs/create-program/), [Create a Class](/programs/classes/create-class/), and [Create a Schedule](/schedules/create-schedule/).

## Create and maintain programs

1. Open **Programs** and choose **New Program**.
2. Give the program a clear name. If age groups need separate classes or enrolments, make the distinction clear, such as **Junior Karate** and **Adult Karate**.
3. Optionally set a minimum or maximum age.
4. Save the program.
5. Add its classes and levels, then create schedules for the classes.

Programs can also have lead-page visibility and waiver settings when the relevant school features are enabled. See [Edit a Program](/programs/edit-program/) and [Configure the Lead Page](/lead-management/lead-page/configure-lead-page/).

## Program access and billing

If your school enables program access checks, billing-plan access can affect which programs members may check in for. This is a school behavior setting, not a change to the member's program membership. Configure access through [billing plans](/billing/billing-plans/set-program-access/) and review [Subscription Behaviors](/settings/behaviors/subscription-behaviors/).
