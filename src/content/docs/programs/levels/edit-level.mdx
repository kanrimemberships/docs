---
title: Edit a Level
description: How to change a level's name or promotion requirements.
---

Levels define the names and progression rules members use within a program. You can rename a level, update its requirements, and change its position in the progression. Review the effects before saving because changes may affect members already working toward promotion.

## Edit a level

1. Open **Programs**, select the program, then open **Levels**.
2. Select the level you want to change and choose **Edit**.
3. Update its name or promotion requirements.
4. Save the level.

Use **Move up**, **Move down**, **Move in**, or **Move out** in the level list to change order or nesting. The level order determines which level comes next.

## Changing promotion requirements

Check the program's [Keep level requirements until next promotion setting](/programs/edit-program/#keep-level-requirements-until-next-promotion) **before** editing.

With that setting off, new minimum days, minimum classes, grading settings, and
next-level assignments apply to existing members immediately. With it on,
memberships already at an affected level keep their previous requirements and
next level until their level changes. Members reaching the level later use
the updated rules.

For example, if you raise a requirement from 20 to 25 classes with the setting
on, an existing member can still qualify at 20. A member who starts that level
after the edit must reach 25. Further edits do not replace the original
requirements kept for the existing member.

Review the [Promotions report](/programs/levels/promotions-report/) before and
after saving, and tell staff which rules apply.

## Before changing the progression

Check the full order before moving or nesting a level. Members at the last
level have no next level to move into. When the program keeps requirements,
existing memberships also keep their old next-level destination, including
having no destination. Do not assume reordering the list updates everyone.

Turning the program setting off clears these kept values and applies the
current progression immediately. This is a program-wide change, not a way to
update one member.

For grading-based progression, review the [Gradings guide](/programs/levels/gradings/). To review how many members qualify, use the [Promotions report](/programs/levels/promotions-report/).
