---
title: Levels
description: A reference for what levels are — the ranking or grading system within a program.
---

Levels are optional ranks within a program, such as belts or grades. They determine a member's current rank and next available promotion.

Set minimum class and day requirements on each level to control when members become eligible to advance. Classes only count when their attendance setting allows them to count toward level requirements.

You can use a normal minimum-days date or set a level's next promotion to the next scheduled grading. Grading dates update automatically when gradings change; member-specific promotion overrides still take precedence. See [Create a Level](/programs/levels/create-level/) and [Manage Gradings](/programs/levels/gradings/).

After promoting a member, their new level becomes current and the promotion date and attendance count reset for the next level. Use the [Promotions Report](/programs/levels/promotions-report/) to review members due to advance.
