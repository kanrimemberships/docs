---
title: Create a Level
description: How to add a level (e.g. a belt or grade) to a program.
---

1. Go to **Programs**, open the program, then open **Levels**.
2. Select **New Level** and enter a name.
3. Set the minimum number of classes and days members must complete before promotion, if needed.
4. To base the next promotion date on a grading, enable **Next promotion is at next grading**.
5. Arrange the level in the progression, then save.

When **Next promotion is at next grading** is enabled, Kanri uses the next scheduled grading for this program after the minimum-days threshold. Create or edit gradings from [Manage Gradings](/programs/levels/gradings/). A member-specific next promotion date overrides the level's setting.

Members must have a next level before they can be promoted. If you leave both minimum requirements unset, date eligibility has no threshold.
