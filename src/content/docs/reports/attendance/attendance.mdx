## Program history

The program shown for an attendance record is saved when attendance is recorded.
Moving a membership to another program does not relabel earlier attendance.
Program filters and CSV exports use this saved program too.

If no program can be determined, the record has no program and is excluded from
filters for a specific program. See
[Historical Attendance](/reports/attendance/historical-attendance/) for older
records and visiting members.
