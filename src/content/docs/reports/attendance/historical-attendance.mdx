---
title: Historical Attendance Report
description: How to use the Historical Attendance report to see attendance trends over time.
---

## Understand the program shown

Attendance keeps the program the member was enrolled in when they attended.
Changing their membership to another program does not move earlier attendance
into the new program. Program filters and exports use the program saved with
each attendance record.

For older attendance, Kanri uses the class's program when the class has just one
linked program. If the class has several programs, it uses the linked membership
to recover the program. Records with no known program remain visible without a
program, but do not appear when filtering for a specific program.

When a member visits another school, attendance stays attributed to their home
membership's program.

## What the chart means

Historical Attendance plots confirmed visits at the school over time. Use it
to compare attendance volume across periods and look for changes worth
investigating. The chart summarizes visits; it is not a member-level list and
does not by itself explain why a trend changed.

## Read the trend carefully

Attendance records keep the program associated with the visit. For older
records, Kanri can use the class's linked program when there is one, or the
member's linked membership when the class has several programs. Records whose
program cannot be identified remain part of the unfiltered totals but are not
included when you filter for a specific program. When a member visits another
school, the visit remains associated with the home membership's program.

To compare like with like, keep the date range and program filter consistent.
For example, compare the same months across years rather than comparing a
complete year with a partial one. Follow up unusual peaks or drops by
reviewing the underlying attendance records and class schedule.

Historical Attendance is a chart rather than the built-in attendance table.
For individual records and confirmation status, use
[Attendance](/reports/attendance/attendance/). For a specific date and class combination
or a custom school scope, use a [Custom Report](/reports/custom-reports/).
