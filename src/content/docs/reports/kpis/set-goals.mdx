---
title: Set KPI Goals
description: Set a target for a KPI and review goal progress over time.
---

Goals let you compare a KPI's actual results with a target. Open the KPI,
choose **Goals**, and select **Manage Reports** access to change the goal.
Staff with view access can review the goal and its history but cannot save
changes.

## Choose a goal type

- **Fixed target** — use the same target each period. Example: aim for 100 new
  memberships every month.
- **Growth rate** — set a percentage increase per period. Choose whether the
  target resets from the previous period's actual result or follows an
  accumulating curve from a baseline. Compare against the previous period or
  the same period last year, and choose the baseline period and value.
- **Reach by date** — set a target value and deadline period. Choose a linear,
  accelerating, or decelerating path from a baseline. The preview shows the
  projected target for each period on the way to the deadline.
- **Manual schedule** — set separate target values for individual periods.
  Use this when seasonal or planned variation makes one repeated target
  unsuitable.

## Save and interpret progress

1. Select the goal type that reflects how you plan to use the KPI.
2. Enter the target, rate, deadline, or period-specific values. For growth
   and reach-by goals, check that the baseline period and value are sensible.
3. Review the preview chart and period table. The chart compares actual values
   with projected targets.
4. Save the goal, then return to the KPI to review progress over time.

Goal values must be finite and non-negative. A target is a planning reference,
not an automatic action or a guarantee. A current period may still be in
progress, so compare its result with the amount of time elapsed before
concluding that it is behind target.

For activity KPIs, the period and date field determine which records count in
each interval. For snapshot KPIs, each point represents the state at the end
of the selected interval. Check the KPI definition before interpreting a goal
curve.
