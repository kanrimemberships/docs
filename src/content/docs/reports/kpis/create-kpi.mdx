---
title: Create a KPI
description: Define a school measure and choose how Kanri calculates and displays it.
---

Use **Reports → KPIs → New KPI** to create a reusable measure. You need
**Manage Reports** permission and access to the records the KPI will use.

## Create the measure

1. **Start with a template or blank KPI.** Choose a template that is close to
   your question, or select **Start from scratch**. You can change a template's
   settings before saving.
2. **Name the KPI and choose what it measures.** Select **Over time** for
   records or events during a date range—for example, membership records created in
   July. Select **At a point in time** for records in a state at the end of
   each period—for example, active memberships at the end of July. Snapshot
   mode is available only for record types that support historical state.
3. **Choose the record type.** Search the list and select the records that
   contain the information you need. The list is limited by your role's
   permissions.
4. **Choose the calculation.** **COUNT** counts matching records. **DISTINCT**
   counts unique values in a field. **SUM**, **AVG**, **MIN**, and **MAX**
   calculate a numeric field, such as a total, average, smallest, or largest
   value. The field picker may let you choose a related field as well.
5. **Add filters if needed.** Use the filter builder to include only records
   that meet your conditions. Leaving the filter empty means all records
   available to that KPI's record type are included.
6. **Choose periods.** For activity KPIs, select a date field and track
   weekly, monthly, quarterly, yearly, or all-time results. For snapshot
   KPIs, select whether to take the snapshot at the end of each week, month,
   quarter, or year. When the period supports it, you can compare with the
   previous period or the same period last year.
7. **Set the history length.** Choose how many past periods to show in the
   mini chart, from 1 to 24. The default is 6. Save the KPI when the
   definition matches your question.

## Example: count new memberships

To count membership records created each month, select **Over time** and
**Membership**, choose **COUNT**, and use **Enrolled On** as the date field.
This date is when the membership record was created, not necessarily when its
status became active. Choose **Monthly** and set a comparison if useful.
Verify the KPI's filters and period description after saving; changing
filters can materially change the result.

## Review or change a KPI

Open the KPI from the library to see its current result, definition, filters,
history, and any goal. If you have **Manage Reports**, choose the edit action
to update it. Viewing and editing also require access to the KPI's source
records. A KPI can be removed from the library by an authorized user; taking a
card off the homepage only changes the dashboard selection.
