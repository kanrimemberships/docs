---
title: Recent Promotions Report
description: Review members who have advanced to a new level recently.
---

Recent Promotions lists memberships whose recorded **last promotion** falls
within the selected date range. It helps you review the most recent level
change on each membership; it is not an event-by-event history of every
promotion and does not identify members who are eligible for a future
promotion.

## Review recent changes

1. Set the start and end dates for the period you want to review.
2. Optionally select a program or level to narrow the results.
3. Open the member or membership record to confirm the current level and
   promotion details.

The date range is based on the saved last-promotion date. For example, to
review promotions recorded during the previous month, select that month's
first and last dates, then choose a program if you want to review one grading
cohort. If a membership has been promoted again since, the report reflects
its latest recorded promotion rather than showing each earlier step.

For current eligibility, use [Promotions](/reports/memberships/promotions/).
For instructions on changing a member's level, see
[Levels and Promotions](/programs/levels/).
