---
title: Memberships Report
description: How to use the Memberships report to see all current enrolments across your school.
---

The Memberships report is a current roster of membership records. It shows
the member, program, level when enabled, status, class counts, remaining
sessions, promotion information, and waiver status when that feature is
available. Use it to review enrolments rather than to measure how many
membership records created during a past period.

## Filter the roster

The report starts with active memberships. Use the member, program, level, or
status filters to narrow the list. Choose **Show inactive** when you need to
include memberships that are no longer active. The report's table can be
sorted by its available columns, and the report provides a CSV download for
the filtered results.

**Remaining sessions** and **class count** are membership-specific values.
Check the underlying membership if a value looks unexpected; do not interpret
the roster as a payment or subscription report.

## Example

To check active enrolments in one program, select the program and keep
**Show inactive** off. To find a former member's membership history, search
for the member and include inactive memberships. For changes over a date
range, use [Historical Memberships](/reports/memberships/historical-memberships/)
instead.
