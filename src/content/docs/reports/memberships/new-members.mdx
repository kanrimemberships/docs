---
title: New Members Report
description: Find members whose first membership record was created during a date range.
---

New Members lists people whose **earliest membership record was created within
the selected date range**. It does not use the date their member profile was
created or the membership's start date. A person added to Kanri earlier can
therefore appear here if their first membership record was created during the
period.

## Use the report

1. Choose the start and end dates for the period you want to review.
2. Review the matching members and their program, **Joined** date, and
   referrer when available.
3. Open a member's record to verify their enrolment or continue follow-up.
4. Download the report as CSV if you need to work with the filtered list
   outside Kanri.

For example, to identify members whose earliest membership record was added
during October, select October 1 through October 31. This report answers
“when was their first membership record created?” rather than “when was their
profile entered?” Use
[Memberships](/reports/memberships/memberships/) for the current membership roster.
