Custom Reports lets you choose which school records to analyze, select fields, apply filters,
and display the results in tables, charts, or single-value stats. Start from a report template
or build a report from scratch. You can put multiple views in one report and control report
visibility separately from each view's visibility.

## A good way to build a report

1. Start with the question you need to answer, such as “Which members joined this month?”
2. Choose the record type that contains the information. For that example, choose **Member**.
3. Add a table when you need to review individual records, a chart when you need to compare
   groups, or a stat when you need one total.
4. Add only the fields and filters that answer your question. Check the sample results before
   saving.
5. Decide who should be able to open the report and its views. Check access with a staff member
   whose role differs from yours if the report will be used by a team.

The field picker is permission-aware: each staff member may see a different selection of
records, fields, and related information. The picker in your school is the current reference
for what you can report on.
