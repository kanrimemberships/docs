---
title: Create a Custom Report
description: Start a custom report from a template or build one from scratch.
---

Use a custom report when the built-in reports do not answer your question or when you want to
combine a table, chart, and summary stats in a reusable view.

## Create the report

1. Open **Reports → Custom Reports** and select **New Report**. You need permission to manage
   reports to create or change one.
2. Choose a template if it is close to what you need. Templates start with sample blocks that
   you can adjust. Use the template search and categories to narrow the choices.
3. If you prefer to design the report yourself, select **Start from scratch**.
4. Enter a clear **Name**. Add a **Description** if you want to explain the report's purpose or
   how staff should interpret it.
5. Choose **Private** or **School Shared** for the report, then select **Create Report**.

For example, name a report **New Members This Month** and describe it as “Members whose
profiles were created this month; check each record before contacting them.” The name and
description make the report's purpose clear to colleagues.

## What happens next

A report created from a template includes the template's views and blocks. A report started
from scratch is created without those template blocks; open it and add a view and report blocks
to define what it shows.

In a view, add a **Table** to review individual records, a **Chart** to compare groups, or a
**Stat** to show one calculated value. A view can contain several charts and stats, but only
one table. Continue with [Report Records and Fields](/reports/custom-reports/record-field-reference/)
to choose data, then use the relevant guide:

- [Build Filters](/reports/custom-reports/filter-builder/)
- [Configure Tables](/reports/custom-reports/configure-tables/)
- [Configure Charts and Summary Cards](/reports/custom-reports/configure-charts-and-stats/)

## Choose access deliberately

Report visibility and view visibility are separate settings:

- **Private** means only the report's creator can open it. **School Shared** makes it available
  to staff with report-viewing access.
- A view can be **Personal (only me)** or **Shared (all viewers)**. A personal view is useful
  for an individual's layout or analysis without changing the shared view.

Staff still need the relevant permissions for the records and fields used by a view. A shared
report does not grant access to data that a staff member's role does not allow them to see.
See [Share a Report](/reports/custom-reports/share-report/) for the full access model.
