---
title: Activate and Deactivate Schedules
description: Start a schedule to generate sessions or stop it and cancel future bookings.
---

An inactive schedule is a template and does not create sessions. Activate it when you are ready for its class entries to appear on the timetable. Deactivate it when the schedule should stop.

## Activate a schedule

1. Open **Schedules** and select an inactive schedule.
2. Add or review the schedule's class entries.
3. Choose **Activate**.
4. Set an **Effective Date**. Leave it blank to activate immediately.
5. Optionally set an **End Date**. Sessions stop appearing on that date and the schedule is automatically deactivated.
6. Select **Activate** and check **View Current Schedule**.

If you set both dates, the end date must be later than the effective date.

## Deactivate a schedule

1. Open **Schedules** and select the active schedule.
2. Choose **Deactivate**.
3. Review the number of future confirmed bookings that will be cancelled.
4. Confirm the deactivation only if cancelling those bookings is intended.
5. Notify affected members through your usual communication process.

Deactivation removes the schedule's live sessions and cancels confirmed bookings dated today or later, even if today's class time has already passed. Reactivating does not restore those cancelled bookings.

For a one-day closure, use a [closed day](/calendar/closed-days/) instead of editing a recurring entry. Entry changes affect the repeating timetable after sync, not just one occurrence.
