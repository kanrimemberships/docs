---
title: Taking Attendance
description: Record whether booked members attended a session, and add attendance for members without a booking.
---

After class, update each booking to show whether the member attended or was a no-show. These booking statuses help staff review class activity and appear in booking reports.

## Mark a booked member

1. Open **Members** and select the member.
2. Open **Bookings**.
3. Select the booking for the session.
4. Choose **Mark Attended** if the member came, or **Mark No Show** if they did not.
5. Repeat for the other members booked into the session.

Do not cancel a booking to record a no-show. Cancellation means the member gave up the spot before class. See [Mark a Booking as Attended or No-Show](/members/bookings/mark-attended-no-show/).

:::caution[Booking status is not an attendance record]
**Mark Attended** changes the booking status only. It does not create the attendance record used for level progression or deduct session credits. Use the kiosk or add attendance manually to record the visit. Check existing attendance first to avoid recording the same visit twice.
:::

## Confirm kiosk check-ins

1. Open **Kiosk** and choose **Open Attendance**.
2. Select the class session and the member's pending sign-in.
3. Select **Confirm Sign-In** after confirming the member is present.

When staff confirmation is required, pending sign-ins do not count toward attendance until confirmed. The shared kiosk and [mobile check-in](/kiosk/mobile-check-in/) have separate confirmation settings.

## Record attendance without a booking

If a member attended but had no booking, add attendance from their profile instead:

1. Open the member and select **Attendance**.
2. Choose **Add Attendance**.
3. Select the member's active membership and a class from the same program.
4. Enter **Number of Attendances** from 1 to 25. Review **Bill Session Usage** if shown, then select **Create**.

See [Add Attendance Manually](/members/attendance/add-attendance-manually/) for field details and limits.

## Review the class afterward

Use the [Bookings Report](/reports/bookings/bookings/) to compare confirmed, attended, no-show, and cancelled booking counts over time. The report counts bookings, not unique people or session fill rates.
