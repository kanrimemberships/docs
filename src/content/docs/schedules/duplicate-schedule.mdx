---
title: Duplicate a Schedule
description: Copy a schedule's recurring class entries into a new schedule.
---

Duplicating is useful when a new term follows the same timetable as an earlier one. Kanri copies the schedule's class entries into a new schedule. The copy is not activated automatically.

## Duplicate a schedule

1. Open **Schedules** and select the schedule to copy.
2. Choose **Duplicate**.
3. Enter a unique name, such as **Spring Term Evening Classes**.
4. Select **Duplicate**.
5. Review the copied entries, then update dates, times, locations, and booking settings for the new term.
6. Set the effective and end dates, then [activate the new schedule](/schedules/activate-deactivate/).
7. Confirm its sessions appear on the current schedule.

The new schedule is separate from the original. Changes to one do not update the other. Because the duplicate starts inactive, it does not create sessions until you activate it.

The original schedule's effective and end dates are not copied. Set the new dates deliberately. For consecutive terms, make the old schedule's **End Date** the first date of the new schedule, because the end date itself is excluded. Check that both schedules will not offer duplicate class times.
