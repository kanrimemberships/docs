---
title: Session Bookings
description: Find upcoming bookings, check session availability, and review booking activity.
---

A booking reserves a place for a member or trial visitor in one session on one date. Staff can review all upcoming or past bookings, check availability, and manage an individual's booking from their profile.

## Find bookings

- Open **Bookings** to view the school's bookings. Staff with permission can switch between all upcoming and all past bookings.
- Open a member's profile and choose **Bookings** to see that member's upcoming or past bookings.
- Use **Availability Preview** to inspect bookable sessions and remaining spots. The preview is read-only; it does not create a booking.

## Make a booking

Start from [Bookings → Create Booking](/schedules/bookings/add-booking/) or from the member's **Bookings** tab. Select an available session and booking type. Kanri checks the booking window, capacity, and class booking settings.

Trial bookings are only available for sessions enabled for trial booking. A regular booking requires a current membership in a program associated with the class.

The regular membership must have an active status. Staff with permission to manage bookings can explicitly override full capacity, but the other booking checks still apply. If trial spots are shared, both booking types use the member-spot limit; if separate, each uses its own limit.

## After the session

Open the member's booking and mark it **Attended** or **No-show**. Use **Cancel** when the member gives up their spot before the class. See [Taking Attendance](/schedules/taking-attendance/).

Changing the booking status alone does not create the attendance record used for promotion or session billing. Use kiosk check-in or manual attendance for that record, and check for an existing record first.
