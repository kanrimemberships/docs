Use the built-in [Bookings report](/reports/bookings/bookings/) to review confirmed, attended, no-show, and cancelled booking activity over time. The report includes summaries by program and class.

## Review booking trends

1. Open **Reports → Bookings**.
2. Choose **Last 30 days**, **Last 90 days**, **Last 6 months**, or **Last year**. You can also choose a named month.
3. Group the trend by day, week, or month.
4. Review the booking-status lines and the program and class summaries.
5. Export the booking records if you need to review individual entries.

The report counts bookings, not unique members, class capacity, or fill rate. A member can have several bookings in the selected period. The class summary shows up to 20 classes with the most bookings.

The period uses the booked session date, not the date the reservation was created. **Attended** here is a booking status, not a count of attendance records used for promotion or billing. You need permission to view bookings to open this report.

The report starts with the last 90 days grouped by week. A named month offers day or week grouping. **Export CSV** uses the selected period too. For a named month, it includes only booked dates in that calendar month, even if a rolling range was selected earlier.

## Example

To investigate whether no-shows increased during the past six months, select the 180-day range and group by week. Compare the no-show count with the other booking statuses, then review the underlying records before changing capacity or booking settings.
