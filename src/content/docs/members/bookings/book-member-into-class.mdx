Use a member's **Bookings** tab to reserve a spot in an upcoming session.

## Before you start

Make sure:

1. The class has sessions in [Schedules](/schedules/).
2. The session allows the kind of booking you need, regular or trial.
3. The session is within your school's booking window and has room available.

## Book a member into a class

1. Open the member from the [Members list](/members/).
2. Open the **Bookings** tab.
3. Click **New Booking**.
4. Review the available sessions in the calendar or week view.
5. Select a session and choose the booking type offered.
6. Add a note if needed.
7. Save the booking.

Kanri checks whether the member has an active [membership](/members/memberships/) in the program. Members without one can only use a trial spot when trial bookings are enabled for that session.

:::caution
If a session is full or falls outside the booking window, you cannot book the member into it.
:::
