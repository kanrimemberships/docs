---
title: Reschedule a Booking
description: Move a confirmed booking to another available session.
---

Reschedule a booking when a member needs a different class date or time. Only confirmed bookings can be rescheduled. Cancelled or completed bookings remain in the member's history and cannot be moved.

You need the **Manage Bookings** permission, and the Bookings feature must be available to your school.

## Reschedule a confirmed booking

1. Open **Members** and select the member.
2. Open **Bookings** and select the confirmed booking.
3. Choose **Reschedule Booking**.
4. Review the available sessions for the same program.
5. Select a replacement session with space.
6. Select **Reschedule to This Class** to confirm the change.
7. Check the booking details to verify the new date and time.

Kanri applies the school's booking window, same-day booking rules, age limits, session capacity, and closed-day rules. If the member cannot select the session, check those rules and whether the session allows regular or trial bookings. For a session that supports both types, staff can select **Trial booking** to change the booking type. If the session is full, staff can explicitly override capacity.

## Example

If a member has a confirmed Monday booking but needs Wednesday instead, open the Monday booking, select **Reschedule Booking**, and choose the Wednesday session if it is available. The member keeps one booking, moved to the new session.

If no suitable session is available, leave the original booking unchanged and contact the member before cancelling it. See [Booking Settings](/settings/booking-settings/) and [Set Closed Days](/calendar/closed-days/).
