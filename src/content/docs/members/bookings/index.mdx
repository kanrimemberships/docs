Use a member's **Bookings** tab to place them in a class session and review the result afterward. Bookings are tied to a specific session, date, and time. See [Schedules](/schedules/) to learn how sessions are created.

## Understand booking options

- A member with an active [membership](/members/memberships/) in a program can book a regular spot when that session allows it.
- A member without an active membership in a program can only book a trial spot when that session allows trial bookings.
- The school's booking settings and the session's available capacity also apply.

## Manage a member's booking

1. [Book the member into a session](/members/bookings/book-member-into-class/).
2. [Reschedule a confirmed booking](/members/bookings/reschedule-booking/) when the member needs a different session.
3. [Edit the booking note](/members/bookings/edit-booking/) without changing its session.
4. [Cancel a booking](/members/bookings/cancel-booking/) when the member no longer needs the spot.
5. [Mark the booking attended or no-show](/members/bookings/mark-attended-no-show/) after class.

:::tip
Regular and trial bookings can have separate capacity limits. Check the session before booking if you are unsure which type to use.
:::
