---
title: Member Discounts
description: Save discounts on a member's profile and choose them when creating an invoice.
---

A member discount is a saved amount that staff can choose while building an invoice for that member. It is not applied automatically. Use a discount when the same member-specific adjustment may be needed on future invoices.

To add or manage discounts, you need the **Manage Billing** permission and the Billing feature.

## Add a discount to a member

1. Open the member's profile and go to **Discounts**.
2. Choose **Add Discount**.
3. Enter a clear name, such as *Sibling discount* or *Staff family discount*.
4. Choose **Flat** for a fixed amount or **Percent** for a percentage.
5. Enter the amount. For example, enter `20` for a $20 flat discount or `10` for 10 percent.
6. Optionally enter start and end dates. If you enter both, the end date must be later than the start date.
7. Save the discount.

Use a descriptive name so the person preparing an invoice can tell why the discount exists. Check the currency displayed in Kanri when entering a flat amount.

## Apply a discount to an invoice

1. Start an invoice for the member.
2. In the invoice builder, look for the member's available discounts.
3. Select the discount you intend to use.
4. Review the invoice total and discount before saving or sending the invoice.

Saving a discount on the member's profile does not apply it to invoices by itself. Select it for each invoice where it should be used.

## Example

If a family receives a 10% discount on tuition, save a *Family tuition discount* as a percentage discount. When preparing a tuition invoice, select that discount and verify the resulting total before sending it.

## Manage a saved discount

Review the member's Discounts area when an arrangement changes. Edit the amount or dates if the discount should continue under different terms, or remove it if it should no longer be offered. This controls whether staff can select it for future invoices; review existing invoices separately in the member's [billing history](/members/billing/).
