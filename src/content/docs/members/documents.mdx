---
title: Member Documents
description: Send, store, and review documents on a member's profile.
---

The **Documents** area on a member's profile keeps that person's files and signature requests together. You can send a school document for signing or upload a file that was completed elsewhere.

Before sending documents, set up the form under [Document Templates](/documents/templates/). For the school-wide document workflow, see [Document Management](/documents/).

## Send a document for signing

1. Open the member's profile and choose **Documents**.
2. Select the option to send a document.
3. Choose a document template.
4. Review the recipient and signer details. Select the member or the appropriate contact when the form offers that choice.
5. Complete any additional fields the template requires, such as a program or subscription.
6. Confirm the email address and send the request.

The recipient receives a link to review and sign the form. A document may also require a witness, depending on how its template is configured.

## Upload an existing file

Use an upload when the document was already signed or completed outside Kanri.

1. On the member's **Documents** tab, choose **Upload**.
2. Select the file from your device.
3. Enter a name that will make sense to other staff, such as *2026 competition waiver*.
4. If the document has an expiry date, enter it.
5. Save the document.

An expiry date records when the document expires. It does not change the document's contents.

## Review a document

The member's document list shows each document's name and status. Open an item to review its details. Depending on the document's status, you may be able to download the completed file, resend a pending signing request, or void a request that should no longer be used.

Check the status before sending another copy. If the signer has not received a pending request, verify the email address first, then use the resend action if it is available.

## Example: annual waiver

Create an annual waiver template once, then send it from each member's profile when the school needs a new signature. Use an easy-to-recognize name and check the member's document list to see whether the request is still waiting for a signature or has been completed.
