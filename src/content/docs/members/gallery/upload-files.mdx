Upload files to keep member-specific documents and media in one place.

## Before you start

Decide:

1. What name staff should see for the file.
2. Whether the file belongs in a folder.
3. Whether the member should be able to see it in the [Member Portal](/member-portal/).

## Upload a file

1. Open the member from the [Members list](/members/).
2. Click **Gallery**.
3. Click **Upload**.
4. Drag the file into the drop zone, or click the drop zone to choose a file.
5. Enter a **Name**.
6. Add a **Description** if helpful.
7. Select a **Folder** if you want to organize the file.
8. Turn on **Public** if the member should see it in the portal.
9. Save the upload.

## Know what each field means

| Field | What it does |
| --- | --- |
| Name | Required. This is the label staff will see. |
| Description | Optional. Add extra context, such as `Black belt test photos`. |
| Folder | Optional. Places the file inside a folder. |
| Public | Makes the file visible in the member portal, if the folder also allows it. |

:::caution
If you place a file inside a private folder, the file cannot be public.
:::

:::tip
Give files names that make sense later. For example, `Yellow Belt Certificate - May 2025` is easier to find than `IMG_2048`.
:::
