The member gallery stores files and folders for one specific member.

This gallery is separate from the school-wide [Gallery](/gallery/). Use it for items that belong to one person, such as grading photos, signed forms, or progress documents.

## Understand member gallery privacy

Each gallery item and folder can be marked **Public** or private.

- Public items can be seen by the member in their [Member Portal](/member-portal/).
- Private items stay staff-only.
- If a file is inside a non-public folder, that file cannot be public.

## Organize files with folders

You can create folders and nested folders to keep a member's files tidy.

For example, you might create folders such as:

- Grading Photos
- Waivers
- Competition Forms
- Progress Videos

## What you can do here

1. [Upload files](/members/gallery/upload-files/).
2. [Manage folders](/members/gallery/manage-folders/).

:::tip
Use clear folder names so staff can find files quickly. For example, use `2025 Grading Photos` instead of `Misc`.
:::
