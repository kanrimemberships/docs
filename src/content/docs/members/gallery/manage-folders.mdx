Use folders to keep a member's gallery neat and easy to search.

## Create a folder

1. Open the member from the [Members list](/members/).
2. Click **Gallery**.
3. Choose the option to add a folder.
4. Enter a **Name**.
5. Add a **Description** if helpful.
6. Turn on **Public** if the member should be able to see files in that folder.
7. Choose a **Parent Folder** if you want this folder nested inside another folder.
8. Save the folder.

## Use nested folders

Nested folders let you group files inside a larger folder.

For example:

- Progress Photos
  - 2024
  - 2025
- Competition
  - Registrations
  - Results

## Edit a folder carefully

When you change a folder from public to private, the privacy change affects items inside it.

:::caution
If a parent folder is private, child folders and items inside it cannot stay public.
:::

## Choose a simple structure

Try to keep folder names consistent.

A good structure often uses one of these approaches:

1. Organize by year.
2. Organize by document type.
3. Organize by event.
