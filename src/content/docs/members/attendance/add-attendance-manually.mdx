Use manual attendance when you need to add training history for one member.

You need the **Manage Members** permission, and Memberships must be available to your school.

## Before you start

Make sure:

1. The member already has an **active** [membership](/members/memberships/assign-membership/).
2. If you select a class, it belongs to the same program as the membership you plan to use.

## Add attendance manually

1. Open the member from the [Members list](/members/).
2. Click **Attendance**.
3. Click **New** or **Add Attendance**.
4. Select the **Membership** you want to use.
5. Select a **Class** if you want to associate the attendance with one. This field is optional.
6. Enter **Number of Attendances**.
7. Click **Create**.

## Know what each field does

| Field | What to enter |
| --- | --- |
| Membership | Choose one of the member's active memberships. |
| Class | Optional. If selected, the class must belong to the same program as the membership. |
| Number of Attendances | Enter how many attendance entries to add. The default is 1. You can add from 1 to 24 at a time. |
| Bill Session Usage | When a billable subscription is available, this option controls whether attendance uses subscription session credits. It is separate from the membership's **Sessions Remaining** count. |

:::caution
If you select a class from a different program, Kanri will not allow the attendance to be created. Leaving Class blank is allowed.
:::

:::tip
Manually adding attendance does not reduce a membership's **Sessions Remaining** count. If a billable subscription applies and **Bill Session Usage** is selected, the attendance can instead use that subscription's session credits.
:::

## When to use manual attendance

Manual attendance is useful when:

- You are catching up after a missed class.
- You need to correct a paper sign-in sheet.
- You want to add several past visits for one member.

For day-to-day class management, [Take Attendance](/schedules/taking-attendance/) is usually faster.
