Add a payment method when you want Kanri to collect payment details through Stripe.

## Before you start

Make sure:

1. Stripe is set up for your school.
2. You know who will pay. You can select the member or a linked contact in the **Bill To** field.

## Add a payment method

1. Open the member from the [Members list](/members/).
2. Open **Billing**, then **Payment Methods**.
3. Click **New Payment Method**.
4. Enter a **Label**.
5. Choose who will pay in the **Bill To** field.
6. Choose **Email Link** to send a secure setup link, or **Collect via Terminal** to collect card details in person using a connected Stripe Terminal reader.
7. Ask the payer to complete the secure setup.

## Important things to know

- You do **not** type card details into the admin panel.
- With **Email Link**, Kanri sends a secure Stripe link so the selected payer can enter their own payment details.
- **Collect via Terminal** is available when your school has a Stripe Terminal reader set up.

## Payment method types you may see later

After setup, the payment method on file can appear as:

- **Card**, for a credit or debit card
- **Canadian bank account**, for Canadian pre-authorized debit
- **US bank account**, for a US bank account

:::tip
If a parent is paying for a child, add the parent as a [contact](/members/contacts/) first. Then select the parent in the **Bill To** field.
:::
