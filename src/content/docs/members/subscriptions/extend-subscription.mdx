Use **Extend** to set up a following subscription term for an eligible end-dated subscription. It creates a separate subscription; it does not change the original subscription's end date or payment history.

## Before you start

You can only extend an end-dated subscription when:

1. its price type is **Paid in Full**, **Fixed Term**, or **Scholarship**
2. it is not already cancelled

## Extend a subscription

1. Open the member from the [Members list](/members/).
2. Click **Billing**, then **Subscriptions**.
3. Open the subscription.
4. Select **Extend**.
5. Choose the price and enter the date the new term should begin.
6. Select **Create Subscription**.

Kanri creates another subscription for the member using the selected price and start date. The original subscription remains unchanged.

You can set the new term to begin on the day after the original subscription ends. Adjacent terms are allowed; they do not count as overlapping.

:::note
Ongoing subscriptions do not need to be extended. They continue until you [cancel the subscription](/members/subscriptions/cancel-subscription/).
:::

:::caution
You cannot use **Extend** for a cancelled subscription. If the member should continue paying, create a new subscription after reviewing the cancellation and payment history.
:::
