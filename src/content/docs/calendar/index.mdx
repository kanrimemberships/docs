When the grading feature is enabled, scheduled gradings also appear in the calendar. Use the **Gradings** layer in the sidebar to show or hide them. Staff with program-view access see all gradings; members see gradings for their active programs. See [Manage Gradings](/programs/levels/gradings/).

## Planned guides

- [Manage Calendars](/calendar/manage-calendars/): create calendars and control who can view them.
- [Create and Edit Events](/calendar/events/): add one-time or repeating school events.
- [Set Closed Days](/calendar/closed-days/): mark days when classes or bookings should not run.
- [Share a Calendar Feed](/calendar/share-calendar-feed/): view calendar events in another calendar app.
- See [Schedules](/schedules/) for recurring classes and generated sessions.
