---
title: Create and Edit Events
description: Add one-time or repeating events to a calendar and edit the right occurrence.
---

Use calendar events for activities that belong on the calendar but are not recurring class schedules, such as belt ceremonies, parent meetings, or tournaments. Use [Schedules](/schedules/) for recurring classes that generate sessions and attendance records.

You need write access to at least one calendar, or permission to manage calendars. A private calendar's events are not automatically visible to every member.

## Create an event

1. Open **Calendar** and navigate to the event date.
2. Select a time on the calendar or use its **New Event** action.
3. Enter a **Title**, up to 200 characters, that staff and members will understand, such as *Belt ceremony*. Use [Gradings](/programs/levels/gradings/) instead if the event should control promotion eligibility.
4. Choose the calendar where the event belongs.
5. Set the start and end dates and times, or turn on **All day**. The end must be after the start. Check the device's time zone before entering times; the event form uses your browser's local time.
6. Optionally add a **Description** and choose a color. Include a room or venue in the description if useful.
7. If the event repeats, choose the recurrence pattern and review the dates shown.
8. Select **Create event** and confirm it appears on the intended calendar.

For example, create *Parent Information Night* on the school calendar for Thursday, 6:30–7:30 p.m. Keep it as a one-time event unless it is genuinely repeated.

For repeating events, turn on **Repeat**, choose a daily, weekly, monthly, or yearly pattern and its interval, and review the **Ends** option. A new pattern starts weekly with no end. Set an end date or occurrence count for a term-limited event rather than leaving it open-ended.

## Edit a repeating event

When editing a recurring event, choose the scope carefully:

- **This event only** changes only the selected date. Use it for a one-off room or time change.
- **This and all following events** splits the series at the selected date. Use it when the event changes from that date onward.
- **All events in the series** changes the recurring event everywhere it applies. This is the initial edit selection, so check it before saving.

For example, if one Monday meeting moves to another room, edit only that occurrence. If every Monday meeting moves to a new time starting next month, edit this and following occurrences from the first changed Monday. Changing a class's actual scheduled session requires the schedule editor instead.

After saving a recurring-event change, review both the occurrence you changed and the remaining series. If the event belongs to a calendar with restricted access, you need permission to write to that calendar.

## Delete an event

Open the event and choose **Delete**. For recurring events, choose **This event only**, **This and all following events**, or **All events in the series** before confirming. The initial delete selection is **This and all following events**. Deleting a calendar event does not delete a schedule session or attendance record.

See [Manage Calendars](/calendar/manage-calendars/) to control who can see or edit calendars, and [Set Closed Days](/calendar/closed-days/) to block activities on a date range.
